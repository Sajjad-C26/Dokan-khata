# দোকান খাতা

ছোট ব্যবসার জন্য অর্ডার ও মালামালের হিসাব রাখার অ্যাপ। PWA হিসেবে বানানো, তাই ফোনে ইনস্টলও করা যায়।

## GitHub-এ আপলোড করার ধাপ (কোনো কোড কমান্ড ছাড়া)

1. https://github.com এ লগ ইন করো
2. উপরে ডানদিকে **+** আইকনে ক্লিক করে **New repository** বাছাই করো
3. Repository name দাও: `dokan-khata`
4. **Public** বাছাই করো, তারপর **Create repository**
5. পরের পেজে **"uploading an existing file"** লিংকে ক্লিক করো
6. এই ফোল্ডারের সব ফাইল ও সাব-ফোল্ডার (src, public সহ সবকিছু) টেনে এনে (drag & drop) আপলোড করো
7. নিচে **Commit changes** বাটনে ক্লিক করো

## Vercel-এ Deploy করার ধাপ

1. https://vercel.com এ যাও, **"Continue with GitHub"** দিয়ে সাইন আপ করো
2. Dashboard-এ **"Add New" → "Project"** ক্লিক করো
3. তোমার `dokan-khata` repository বাছাই করে **Import** করো
4. Framework হিসেবে এটা নিজে থেকেই **Vite** সনাক্ত করবে — কিছু বদলাতে হবে না
5. **Deploy** বাটনে ক্লিক করো
6. ১-২ মিনিটের মধ্যে একটা লাইভ লিংক পাবে (যেমন: `dokan-khata.vercel.app`)

## ফোনে ইনস্টল করা

লিংকটা ফোনের ব্রাউজারে খুলে মেনু থেকে **"Add to Home Screen"** বাছাই করলেই এটা একটা app আইকনের মতো বসে যাবে।
